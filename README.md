# Lab Report Writer

一个面向大学实验课程的 AI Skill，用于根据实验指导书、课件、PDF、Word 文档或图片，整理实验预习报告与实验报告。

默认中文输出，强调**忠于原始实验材料、内容简洁、步骤流程图化、数据记录规范、计算过程完整**。

## 功能特点

- **忠于材料**：不擅自补造实验条件、试剂用量、实验数据或实验现象。
- **原理精简**：优先使用化学反应方程式、反应式或计算关系式表达。
- **浓度完整**：材料中给出的试剂浓度和单位必须保留。
- **流程图步骤**：使用方框和箭头呈现实验步骤，并标注关键试剂、用量、温度、时间及测定条件。
- **数据表规范**：先提供汇总空表，再提供细分记录表；每张表均有表号、表名和表头。
- **计算过程完整**：先列公式和符号单位，再逐次代入数据；平行实验分别计算后再求平均。
- **结论有依据**：定量实验报告结果及单位，定性实验依据实际现象作出判断。

## 适用场景

适用于食品分析、食品营养、化学、生物及相关专业的大学实验课程。具体内容以用户提供的实验材料为准。

## 使用方法

### 方法一：在支持 Agent Skills 的工具中使用

将本仓库中的 `SKILL.md` 放入目标工具要求的 Skill 目录，并按该工具的 Skills 规范加载。

不同工具的目录结构、发现机制和启用方式可能不同，请以对应工具的官方文档为准。

### 方法二：作为提示词使用

也可以直接打开 `SKILL.md`，复制其中的指令，粘贴到支持自定义指令或项目指令的 AI 工具中。

### 方法三：通过 Git 克隆

```bash
git clone https://github.com/你的GitHub用户名/lab-report-writer.git
```

将上面的 `你的GitHub用户名` 替换为实际 GitHub 用户名。

## 使用建议

1. 上传实验指导书、课件或其他原始材料。
2. 如有学校或教师指定的实验报告模板，一并提供。
3. 说明本次需要的是预习报告还是正式实验报告。
4. 如需计算，提供真实实验数据；没有数据时，保留待填写位置。
5. 检查生成内容与原始材料是否一致，尤其是试剂浓度、操作条件和计算公式。

## 基本原则

本 Skill 是实验报告整理辅助工具，不替代实验指导书、教师要求或实验室安全规范。遇到材料缺失、表述不清或公式疑点时，应明确指出，不应自行猜测补全。
